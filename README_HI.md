# गीता जीवन मार्ग: Cloudflare Pages डेमो

अभ्यास के लिए नमूना प्रोजेक्ट। लॉगिन (मोबाइल नंबर + एक्सेस कोड), रोज़ का सुविचार, कैटेगरी → समस्या → श्लोक/अर्थ/रोडमैप/वीडियो।

## फ़ोल्डर
```
public/index.html        ← वेबसाइट (पेज)
functions/api/login.js   ← लॉगिन जाँच
functions/api/content.js ← लॉगिन के बाद ही कंटेंट भेजता है
data/content.js          ← सुविचार + समस्याएँ (यहीं कंटेंट बदलें)
data/auth.js             ← टोकन बनाने/जाँचने का कोड
```

## डिप्लॉय का तरीक़ा (GitHub से, सबसे आसान)
1. github.com पर मुफ़्त खाता बनाएँ और एक नया **private** रिपॉज़िटरी बनाएँ।
2. इस पूरे फ़ोल्डर की फ़ाइलें उसमें अपलोड करें (फ़ोल्डर-संरचना वैसी ही रहे)।
3. dash.cloudflare.com पर मुफ़्त खाता बनाएँ → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → अपना रिपॉज़िटरी चुनें।
4. Build सेटिंग: **Framework: None**, **Build command: खाली**, **Build output directory: `public`**। फिर Save and Deploy।
5. डिप्लॉय के बाद आपको `xxxx.pages.dev` लिंक मिलेगा। अभी लॉगिन "सेटअप अधूरा" कहेगा, यह सामान्य है; अगले कदम करें।

> `functions` फ़ोल्डर वाला हिस्सा चलाने के लिए Git या Wrangler से डिप्लॉय करना होता है। ब्राउज़र में सिर्फ़ ज़िप खींचकर डालने वाले तरीक़े में इसके समर्थन की स्थिति Cloudflare के मौजूदा दस्तावेज़ में जाँच लें।

## KV (ग्राहकों की सूची) जोड़ें
1. Cloudflare में **Storage & Databases → KV → Create namespace**, नाम: `gjm-users`।
2. अपने Pages प्रोजेक्ट में **Settings → Bindings (या Functions) → Add → KV namespace**: Variable name = **`USERS`**, namespace = `gjm-users`। Production और Preview दोनों में जोड़ें।
3. **Settings → Variables and Secrets** में **`SESSION_SECRET`** नाम का Secret जोड़ें। मान: कोई लंबा रैंडम पाठ (कम से कम 32 अक्षर)। इसे किसी को न बताएँ।
4. **Deployments** में **Retry deployment** (या नया कमिट) करें, ताकि नई सेटिंग लागू हो।

## ग्राहक जोड़ना (हर ख़रीदार के लिए)
KV namespace खोलकर **Add entry**:
- **Key:** 10 अंकों का मोबाइल नंबर, जैसे `9876543210`
- **Value:** `{"code":"GITA-4821","name":"राम"}`

ग्राहक को यही नंबर और कोड भेजें (हर ग्राहक का कोड अलग रखें)। ग्राहक की पहुँच बंद करनी हो तो वह key हटा दें; उसका लॉगिन तुरंत बंद हो जाता है।

## परीक्षण
लिंक खोलें → नंबर `9876543210`, कोड `GITA-4821` (ऊपर जो entry बनाई) → अंदर जाने पर सुविचार और समस्याएँ दिखेंगी।

## कंटेंट बदलना
`data/content.js` खोलें। हर समस्या में: `ref`, `sanskrit`, `translation`, `explanation`, `roadmap`, `video.id`।
- **वीडियो:** YouTube लिंक `youtube.com/watch?v=XXXXXXXXXXX` में से 11 अक्षर की ID `video.id` में डालें। पहले जाँचें कि वीडियो एम्बेड की अनुमति देता है और उसका उपयोग आपके व्यावसायिक प्रोडक्ट में ठीक है।
- **सुविचार:** `QUOTES` में 365 तक अपने मौलिक सुविचार जोड़ें।
- हर बदलाव के बाद GitHub में सेव (commit) करें; Cloudflare अपने आप दोबारा डिप्लॉय कर देगा।

## ज़रूर ध्यान रखें
- **यह सिर्फ़ अभ्यास का नमूना है।** इसमें 4 समस्याएँ हैं। श्लोकों को किसी प्रामाणिक संस्करण से मिलाएँ, अनुवाद/व्याख्या अपनी लिखें।
- **सुरक्षा की सीमाएँ:** लॉगिन पर गलत प्रयासों की सीमा (rate limit) नहीं है, और एक ही कोड कई लोग साझा कर सकते हैं। बिक्री से पहले इन्हें जोड़ना होगा। लॉगिन के बाद कंटेंट कोई कॉपी भी कर सकता है।
- **गोपनीयता:** आप मोबाइल नंबर रखते हैं, इसलिए गोपनीयता नीति रखें और ज़रूरी क़ानूनी बातें किसी जानकार से पूछ लें।
- **मुफ़्त सीमाएँ:** Workers की फ्री योजना में रोज़ 100,000 रिक्वेस्ट और KV में रोज़ 1,000 राइट तक की सीमा है (सीमाएँ बदल सकती हैं, Cloudflare का मौजूदा पेज देखें)।
